## Q01 · 미러리스 카메라 연장 요청 (L002, 이서준)

| 항목 | 내용 |
|------|------|
| 대여ID / 장비 | L002 / 미러리스 카메라 (CM-01) |
| 현재 반납예정일시 | 2026-10-07 18:00 |
| 희망 반납일시 | 2026-10-08 18:00 |
| 다음예약 | 영상제작팀 2026-10-08 09:00 ~ 2026-10-08 18:00 |

### 충돌 판정: **충돌 (승인 불가 / 조건부)**

- 근거: 연장 시 반납 시각이 **2026-10-08 18:00**이 되는데, 이는 다음예약 시작인 **2026-10-08 09:00**보다 **늦다**. 즉 희망 연장 기간(10-08 전일)이 영상제작팀 예약 시간대(09:00~18:00)와 전면 겹친다.
- 운영메모 기준 3에 따라, 다음 이용자(영상제작팀)에게 영향을 주므로 희망안 그대로의 **전일 연장은 승인할 수 없다**.
- 판정 결론: **희망안(10-08 18:00) 승인 불가**. 아래 대안 중 선택 시에만 조건부 승인 가능.

### 대안 (운영메모 「담당자가 대안을 검토한다」 적용)

1. **부분 연장(조건부 승인)**: 다음예약 시작 전인 **2026-10-08 09:00 직전까지만** 연장. 단, 영상제작팀 예약 준비·회수 시간을 고려하면 실질 여유가 거의 없어 권장도는 낮음. 예약 당일 오전 사용은 반납·점검 지연 위험이 있어 담당자 확인 필요.
2. **반납 후 재대여(권장)**: 10-08 18:00(영상제작팀 반납) **이후** 재대여로 이용자의 추가 사용 수요를 충족. 이용자의 "내일 오전 촬영" 요구와는 시점이 맞지 않을 수 있으므로 일정 조율 안내.
3. **다른 장비 배정**: 동급 미러리스 카메라가 가용하지 않다. 현황상 가용 카메라류는 액션 카메라(CM-02, L006으로 대여 중)뿐이므로 즉시 대체 배정은 불가. 대체 장비 확보 시 배정 검토.
4. **당일 반납 안내(원요청 대안 수용)**: 이용자가 요청문에서 밝힌 "연장이 어렵다면 오늘 촬영분을 옮기고 반납" 의사에 따라, **원래 반납예정(10-07 18:00) 준수**를 안내하고 촬영분 이전을 지원.

→ **Q01 권고**: 희망 전일 연장은 **불가**. 1순위로 대안 4(당일 반납, 다음예약 보호), 이용자 사용 수요가 큰 경우 대안 2(반납 후 재대여)를 함께 안내. step_apply에서 **현황 변경 없음**이 기본.
