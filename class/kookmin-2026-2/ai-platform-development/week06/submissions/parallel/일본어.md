# 学科AI実習ミーティングのご案内

## 概要 / Summary

学科の仲間と一緒にAIを実際に使ってみる実習ミーティングを開催します。定員は12名で、AI実習が初めての学生でも参加できます。英語および日本語での案内は、ミーティング情報を理解していただくために提供するものです。ミーティング当日の案内と実習はすべて韓国語で進行します。

## 集まりの情報 / Meeting Information

| 項目 | 内容 |
| --- | --- |
| 日時 | 2026年10月16日 18:30～20:00（韓国時間 / Asia/Seoul） |
| 場所 | 学生会館 ミーティング室（학생회관 모임실） |
| 定員 | 12名 |
| 持ち物 | 個人のノートパソコンと充電器 |
| Wi-Fi | 会場でWi-Fiを利用できます |
| 参加費 | 無料 |
| 進行言語 | 韓国語（案内・実習ともに韓国語で進行します） |
| 参加対象 | 学科の学生。AI実習が初めての学生も参加可能 |

## 申し込み方法 / How to apply

参加を希望する学生は、2026年10月14日 18:00（韓国時間）までに学科のグループチャットに名前を残してください。別途の申し込みリンクはありません。日付と締め切り時刻を確認のうえ、案内された方法に従って申し込んでください。
