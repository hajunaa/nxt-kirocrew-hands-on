# タイトル：学科AI実習ミーティングのご案内

## 概要

学科の仲間と一緒にAIを実際に使ってみる実習ミーティングを開催します。定員は12名で、AI実習が初めての学生も参加できます。日程は2026年10月16日18:30〜20:00、場所は学生会館のミーティングルームで、参加費は無料です。英語・日本語のご案内はミーティング情報を理解していただくために提供するものであり、**当日の案内および実習はすべて韓国語で進行します**。本案内に記載するすべての時刻はAsia/Seoul（韓国標準時／KST）を基準とします。

| 項目 | 内容 |

| 日程 | 2026年10月16日 18:30〜20:00（Asia/Seoul・KST） |
| 場所 | 学生会館 ミーティングルーム |

| 対象 | AI実習が初めての学生も参加可能 |

## 申込方法

- 参加を希望する学生は、**2026年10月14日18:00（Asia/Seoul・KST）まで**に学科のグループチャットに名前を残してください。
- 別途の申込リンクはありません。日付と締切時刻を確認のうえ、案内された方法に従ってお申し込みください。
